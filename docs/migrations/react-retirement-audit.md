## Резервная Git-копия

Создан полный `git bundle --all` исходного зеркала. Bundle проверен `git bundle verify`, затем восстановлен в отдельное пустое зеркало. Независимое сравнение подтвердило совпадение всех 29 коммитов и 15 именованных refs; дополнительно bundle содержит символический HEAD. Сверка полного множества коммитов всех исходных refs с обходом только целевого `main` дала те же пять исключений, что и проверка веток.

Имя локального архива: `react-retirement-2026-10-19-7de1562-51ed10b9.bundle`.

SHA-256: `f61161170742dcc154448b0c66d47c845f81ce62f02936e1707c74eac75caeda`.

Архив хранится локально у оператора и не публикуется этим PR. Перед удалением репозитория его следует сохранить в согласованном долговременном хранилище. Bundle содержит Git-историю, но не GitHub-обсуждения, настройки, статусы Actions и метаданные закрытых issues/PR.

## Что остаётся перед удалением

1. Принять PR с новым маршрутом `React.`. До merge общий CONTRIBUTING продолжает указывать старый репозиторий.
2. Сохранить пять документальных коммитов и исходные refs в долговременной Git-копии либо принять решение хранить старый репозиторий в архиве. Локальная восстановленная копия проверена; полной достижимости всех 29 коммитов из нового `main` нет.
3. Переключить мониторинг: `scripts/reminders.sh` по-прежнему содержит `Cringe-Driven-Development-Team/react` в `REPOS`, а `frontend-packages` отсутствует в этом списке. Перед удалением нужен отдельный переход мониторинга с соответствующей проверкой `tests/reminders.sh`. Этот PR меняет документацию и не переключает рабочую автоматику.
4. Учесть старые внешние адреса: опубликованный `@maninthecoat/react@1.2.0` указывает repository на старый адрес. Удаление также уберёт доступ к старым GitHub-обсуждениям и ссылкам на PR; Git bundle их не сохраняет. Архивирование оставляет эти адреса доступными.

Проверка не обнаружила уникального кода библиотеки, требующего переноса. Вывод о полной готовности к удалению репозитория не делается: перечисленные зависимости остаются отдельными шагами.
